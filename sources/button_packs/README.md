# button_packs

Made by [Aero_](https://github.com/AeroWidescreen)

HD gamepad button prompts replacing the original ones. One folder per set.

## Layout

- `files/<set>/<TEXTURE>.dds`: named after the game's prompt textures.
- `.sblink`: language variants (`_FRENCH`, `_SPANISH`, ...) and shared icons, linked to one file.
- `LOADING_CONTROLLER_{STICK,DPAD}.dds`: in-game controller pictures.

## Changes

- `xbox_360`: using older pack fitting the original style better.
- `ps3`: colorless face buttons like `ps4` for consistency.
- Controller pictures: the Switch one is based on a picture found online; the rest are generated by Gemini due to lack of fitting sources. `xbox_360` uses the stock one.
